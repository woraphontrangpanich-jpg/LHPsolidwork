# SheetFlat — คลี่ไฟล์ Assembly เป็นแผ่นเรียบ แยก DXF ตามความหนา

เว็บแอปสำหรับโรงงานตัดเหล็กด้วยเลเซอร์ รับไฟล์ Assembly 3D จากลูกค้า แล้วทำ 3 อย่างที่ตอนนี้ต้องทำมือ

1. หาว่า Assembly มีชิ้นส่วนอะไรบ้าง แต่ละชิ้นหนาเท่าไร มีกี่ชิ้น
2. คลี่ชิ้นส่วนที่พับแล้วให้เป็นแผ่นเรียบ โดยหักค่ายืดของรอยพับให้ถูกต้อง
3. รวมชิ้นที่เหล็กหนาเท่ากันและชนิดเดียวกันไว้ใน DXF ไฟล์เดียว พร้อมไฟล์ Excel สรุปรายการทั้งหมด

ชิ้นส่วนที่ไม่ใช่แผ่นตัด (ท่อ น็อต สกรู ชิ้นส่วนซื้อ) จะไม่ถูกใส่ใน DXF แต่ถูกบันทึกในไฟล์ Excel

## เริ่มใช้งาน

```
start.bat            (ดับเบิลคลิก - ติดตั้งครั้งแรกอัตโนมัติ แล้วเปิดเบราว์เซอร์ที่ http://127.0.0.1:8765)
```

หรือใช้ `python run.py` ต้องใช้ Python 3.10 ขึ้นไป (ทดสอบกับ 3.14) โปรแกรมทำงานบนเครื่องของคุณเอง ไฟล์ไม่ถูกส่งออกอินเทอร์เน็ต
ฟอนต์ IBM Plex Sans Thai โหลดจาก Google Fonts ถ้าเครื่องออฟไลน์จะใช้ Leelawadee UI / Tahoma แทน

### ขั้นตอนในหน้าเว็บ

1. อัปโหลด `.step` / `.stp` เลือกชนิดเหล็กของทั้งงาน (ZN เหล็กซิงค์ หรือ ST เหล็กขาว) และโหมดค่ายืด
2. หน้าแรกหลังคำนวณคือ **ใบสั่งตัด** แยกตามวัสดุและความหนา บอกจำนวนแบบ จำนวนชิ้น ขนาดแผ่นคลี่ พร้อมรูปย่อของแต่ละชิ้น และรายการที่ไม่ตัด จากนั้นแสดงไฟล์ DXF ที่จะได้ เรียงเป็นแผ่นตามความหนา (เช่น `ZN#22 0.7 มม.`) คลิกไฟล์เพื่อดูแบบรวม คลิกชิ้นส่วนเพื่อดูแบบคลี่ชิ้นเดียว
3. ตรวจผล ถ้าชิ้นไหนเป็นเหล็กคนละชนิด เปลี่ยนที่ช่อง “ชนิดเหล็ก” ของชิ้นนั้น ไฟล์ DXF จะถูกแยกและคำนวณใหม่ทันที
4. ส่งออก DXF ทีละไฟล์ หรือทั้งหมดเป็น `.zip` (รวมไฟล์ Excel) หรือกด “ส่งออก Excel”

เครื่องมือในพรีวิว: ซูม/เลื่อน (ล้อเมาส์/ลาก), ปุ่ม **ขนาด** แสดงเส้นบอกขนาดรอบแผ่น เส้นผ่านศูนย์กลางรู และมุมพับ, **วัดระยะ** (M) คลิกสองจุด ดูดจุดปลายเส้น/ศูนย์กลางรูอัตโนมัติ, เลื่อนเมาส์ไปที่เส้นเพื่อดูความยาว/ขนาดรู/รัศมี, ปุ่มลัด F ดูทั้งหมด · B เส้นพับ · D ขนาด · N ชื่อ

## หลักการคำนวณ

### 1. หาความหนาและแยกผิวแผ่นออกจากผิวขอบ

ยิงเส้นตรงจากทุกผิวระนาบเข้าไปในเนื้อชิ้นงาน วัดระยะถึงผิวระนาบตรงข้ามที่ขนานกัน ระยะที่พบมากที่สุด (ถ่วงน้ำหนักด้วยพื้นที่) คือความหนา แล้วนำไปเทียบกับตาราง (ห่างไม่เกิน ±0.06 มม.) เพื่อได้เบอร์และค่ายืด ถ้าไม่ตรงตารางจะบอกชัดเจนและใช้ K-factor แทน

### 2. คลี่แผ่น

ผิวด้านหนึ่งของแผ่นประกอบด้วยผิวระนาบ (ส่วนเรียบ) ต่อกันด้วยผิวทรงกระบอก (รอยพับ) ที่สัมผัสกันต่อเนื่อง โปรแกรมไล่ผิวทั้งหมดจากผิวเรียบที่ใหญ่ที่สุด วางแต่ละผิวลงบนระนาบ 2 มิติ และแทนที่รอยพับแต่ละจุดด้วยแถบกว้าง **BA** เส้นตัดคือขอบของผิวที่ติดกับผิวข้างความหนา รูและเส้นโค้งที่ตัดผ่านรอยพับถูกแปลงจุดต่อจุด

### 3. ค่ายืด — รอยพับตั้งฉาก (90°) ใช้ตารางของโรงงาน

ค่ายืดในตารางคือค่าที่ **หักออกจากผลรวมขนาดด้านนอก** ของสองด้านที่พับ

```
ความยาวแผ่นก่อนพับ  =  a + b − BD          (a, b = ขนาดวัดจากด้านนอกของชิ้นที่พับแล้ว)
```

ในแผ่นคลี่ แถบพับมีความกว้าง `BA = 2·(r_in + t) − BD` ผลรวมของแผ่นจึงเป็น `a + b − BD` พอดี ไม่ขึ้นกับรัศมีใน (r_in) ในโมเดล

ตารางเริ่มต้น (จากรูป `ค่ายืด.jpg`)

| เบอร์ | ความหนา (มม.) | ค่ายืด BD (มม.) |
|---|---|---|
| #22 | 0.7 | 1.25 |
| #20 | 0.9 | 1.5 |
| #19 | 1.0 | 1.75 |
| #18 | 1.2 | 2.0 |
| #17 | 1.4 | 2.25 |
| #16 | 1.6 | 2.5 |
| #14 | 2.0 | 3.2 |
| #3mm | 3.0 | 4.8 |

ชื่อกลุ่ม = คำนำหน้าวัสดุ + เบอร์ (`ZN#22`, `ST#14`) ค่าในตารางเท่ากันสำหรับ ZN และ ST

### 4. รอยพับไม่ฉาก และรอยพับโค้ง — ใช้ K-factor

**K-factor คืออะไร** เวลาพับ เนื้อโลหะด้านนอกถูกดึงยาวขึ้น ด้านในถูกอัดสั้นลง ระหว่างกลางมีชั้นที่ความยาวไม่เปลี่ยน เรียกว่า *neutral axis* K-factor = ตำแหน่งของชั้นนั้นเทียบกับความหนา วัดจากผิวด้านใน (K = 0.5 คือกึ่งกลางความหนาพอดี) ความยาวของส่วนโค้งที่ชั้นนี้คือค่าที่แผ่นเรียบต้องมีสำหรับรอยพับนั้น

```
BA = θ · (r_in + K · t)          θ เป็นเรเดียน, r_in = รัศมีด้านใน, t = ความหนา
```

ค่า K ของโรงงานคือ **0.5** (ค่าเริ่มต้น แก้ได้) ใช้กับ

- รอยพับที่ไม่ใช่ 90° (เช่น 45°, 135°) และรอยพับ 180° (hem พับทบ)
- ส่วนโค้งรัศมีใหญ่ (r_in มากกว่า 3 เท่าของความหนา ปรับได้) เพราะตารางค่ายืดใช้ได้เฉพาะรอยพับคม
- ชิ้นที่ความหนาไม่อยู่ในตาราง

**รอยพับสลับทิศติดกันที่ระยะเรียบสั้นมาก (jog / step)** ใช้ K-factor ด้วย ค่าเริ่มต้นนี้ตรงกับที่ SolidWorks คำนวณในไฟล์ตัวอย่าง (ชิ้น Front) ปิดได้ในหน้า “แก้ตารางค่ายืด → ตั้งค่าขั้นสูง”

### 5. โหมดค่ายืด

ตารางค่ายืด + K-factor + เกณฑ์ต่างๆ เก็บเป็น “โหมด” กดสร้างโหมดใหม่จากโหมดเดิมแล้วแก้ค่าเอง บันทึกไว้ที่ `data/profiles.json` เมื่อบันทึก แผ่นคลี่ของงานที่เปิดอยู่ถูกคำนวณใหม่ทันที

### 6. ชิ้นส่วนที่ไม่นำไปตัด

โปรแกรมไม่ใส่ชิ้นเหล่านี้ใน DXF และบอกเหตุผล (กดติ๊ก “นำมาตัดอยู่ดี” ได้ถ้าคลี่ได้)

- ไม่พบความหนาคงที่ / หนากว่า 12.7 มม. (ชิ้นตัน น็อต สกรู)
- ผิวหน้าปิดเป็นวง คลี่ไม่ได้ (ท่อกลม ท่อสี่เหลี่ยม)
- ชื่อมีคำเช่น bolt, screw, nut, washer, pipe, tube, สกรู, น็อต, ท่อ (แก้รายการได้ใน `data/profiles.json` ช่อง `exclude_keywords`)

## วิธีตรวจสอบว่าถูกต้อง (cross-check)

**ในหน้าเว็บ** แต่ละชิ้นมีหัวข้อ “ตรวจสอบความถูกต้อง”

- *พื้นที่คลี่ × ความหนา เทียบกับปริมาตร 3D* คำนวณแยกอิสระด้วย K = 0.5 ถ้าการคลี่ผิด (ขาดผิว วางผิดทิศ) ค่านี้จะเพี้ยนทันที ชิ้นตัวอย่างทั้ง 7 ชิ้นต่างกันไม่เกิน 0.001%
- เส้นตัดทุกเส้นปิดสนิท
- ความหนาที่วัดได้ พร้อมสัดส่วนพื้นที่ที่ยืนยัน
- ตารางรอยพับทุกจุด มุม รัศมี วิธีคำนวณ (ตาราง/K) BD และ BA
- ชี้เมาส์ที่เส้นดูความยาว รูดู Ø ใช้เครื่องมือวัดระยะเทียบกับแบบ

**ชุดตรวจละเอียด** (`tests/test_audit.py`) อ่านไฟล์ DXF ที่ส่งออกกลับมาแล้วคำนวณซ้ำแบบอิสระ

- จำนวนชิ้นใน DXF ตรงกับจำนวนจริงใน Assembly รวม sub-assembly ซ้อน (เช่น 2 ชุดย่อย × ชุดละ 3 ชิ้น = 6 ชิ้น)
- เส้นตัดใน DXF ต่อกันสนิท (ช่องว่างปลายเส้น 0) แต่ละชิ้นมีเส้นขอบนอกปิด 1 วง พื้นที่จาก DXF ตรงกับที่คำนวณ
- เส้นพับในไฟล์ = จำนวนรอยพับ × จำนวนชิ้น ชิ้นไม่ซ้อนกันและห่างตามระยะที่ตั้ง
- ทุกรอยพับคำนวณ BA ย้อนด้วยสูตรว่าตรงกฎ (90° รัศมีเล็ก → ตาราง, อื่นๆ → K-factor)
- กลับด้านแผ่นคลี่เป็นภาพกระจกที่ถูกต้อง แบ่งแผ่นตามขนาดเหล็กไม่ล้นแผ่น และ Excel ตรงกับ DXF ส่วนเส้นขอบที่ไม่ตรงเป๊ะคือรอยบากเล็กตรงปลายรอยพับ ห่างไม่เกิน 0.4 มม. (ชิ้น Hook ไม่มีไฟล์อ้างอิง) รันซ้ำได้ด้วย `python -m pytest`

## ข้อจำกัดที่ควรรู้

- **ไฟล์ `.sldasm` ของ SolidWorks เป็นรูปแบบปิด** ไม่มีโปรแกรมอื่นอ่านได้ และตัวไฟล์เก็บเพียงตัวชี้ไปยัง `.sldprt` ข้างในเท่านั้น โปรแกรมจึงรับ `.sldasm` ได้เฉพาะเครื่องที่ติดตั้ง SolidWorks (สั่งให้ SolidWorks แปลงเป็น STEP ให้เอง ใช้ปุ่ม “เปิดไฟล์ด้วยพาธ”) **ส่วนนี้ยังไม่ได้ทดสอบ เพราะเครื่องพัฒนาไม่มี SolidWorks** ทางที่ทดสอบแล้วและแนะนำคือ Save As เป็น `.step` ข้อมูลความหนาและรอยพับอ่านจาก STEP ได้ครบ
- STEP ต้องเป็นโมเดลที่พับแล้วตามจริง (ไม่ใช่ไฟล์ที่ลูกค้าส่งมาเป็นแผ่นคลี่)
- ยังไม่รองรับ รอยพับรัศมี 0 แบบคม (ไม่มีผิวโค้ง) รอยพับแบบกรวย/ผิวโค้งอิสระ ปั๊มนูน/ครีบ/louver จะเตือนในรายการ “ข้อควรตรวจ”
- ตัวคลี่ใช้ผิวด้านเดียวเป็นฐาน ถ้าเส้นตัดเฉียงผ่านรอยพับ เส้นขอบตรงจุดนั้นอาจเพี้ยนได้ราว 0.1–0.25 มม. เทียบกับการคลี่ตามแกนกลาง ซึ่งไม่ส่งผลกับการตัดเลเซอร์ทั่วไป
- การจัดวางใน DXF เป็นการวางเรียงกรอบสี่เหลี่ยมไม่ให้ซ้อนกัน ไม่ใช่ nesting ประหยัดเหล็ก
- ตารางค่ายืดจากโรงงานใช้ได้กับรัศมีโมเดลประมาณเท่าความหนา (ในตัวอย่าง r = 0.2 มม.) ถ้าลูกค้าใช้รัศมีต่างจากที่หน้างานพับจริง ค่ายืดจริงจะเปลี่ยน

## ข้อเสนอแนะต่อโปรเจกต์ (สิ่งที่ปรับให้ดีกว่า brief เดิม)

1. **จำนวนชิ้นในไฟล์ DXF** ใส่ตามจำนวนจริง (ยืนยันกับโรงงานแล้ว) เช่นเหล็ก 3 มม. 10 ชิ้น ไฟล์ 3 มม. มีครบ 10 ชิ้น หน้า “ใบสั่งตัด” บอกว่าแต่ละความหนามีกี่แบบ กี่ชิ้น
2. **ชื่อไฟล์** `ชื่องาน_วัสดุเบอร์_ความหนา` เพราะเหล็กซิงค์กับเหล็กขาวหนาเท่ากันต้องแยกไฟล์ ถ้าใช้ชื่อแค่ความหนาจะซ้ำกัน แก้รูปแบบได้ที่ `settings.filename`
3. **เส้นพับกับชื่อชิ้น** อยู่คนละเลเยอร์และปิดได้ เพราะเครื่องเลเซอร์บางรุ่นตัดทุกเลเยอร์ ถ้าไม่ปิดจะตัดเส้นพับทิ้ง
4. **ชิ้นส่วนที่เหมือนกันแต่คนละชื่อ** (ซ้าย/ขวาที่ทำแยกไฟล์) ถูกนับเป็นคนละแบบ ถ้าอยากรวม ให้ตั้งชื่อเดียวกันใน SolidWorks
5. **เหล็กโปรไฟล์** (เหล็กฉาก รางตัวซี) ที่ซื้อมาตัดความยาวเอา มีรูปทรงเหมือนแผ่นพับ โปรแกรมจะเตือนเมื่อแผ่นคลี่ยาวกว่ากว้างเกิน 15 เท่า ให้ติ๊ก “ไม่ตัด” เอง
6. ค่ายืดจริงขึ้นกับเครื่องพับ แม่พิมพ์ และเหล็กแต่ละล็อต ถ้าพบว่าชิ้นพับจริงสั้นหรือยาวต่างจากแบบ ให้ปรับตารางในหน้า “แก้ตารางค่ายืด” แล้วคำนวณใหม่ ไม่ต้องแก้ที่ตัวแบบ 3D

## โครงสร้างโปรเจกต์

```
sheetflat/
  run.py, start.bat, requirements.txt
  sheetflat/
    app.py                 FastAPI (อัปโหลด, ประมวลผล, ส่งออก)
    core/
      step_reader.py       อ่าน STEP / assembly (OpenCASCADE) นับจำนวนชิ้น
      brep.py              ดึงผิว/ขอบ/วงปิดจาก B-rep เป็นตัวเลข (numpy)
      analysis.py          หาความหนา แยกผิวแผ่น/รอยพับ
      unfold.py            คลี่แผ่น สร้างเส้นตัด/เส้นพับ ตรวจวงปิด
      bend.py              BA จากตารางค่ายืด / K-factor
      profiles.py          โหมดค่ายืด (บันทึกใน data/profiles.json)
      project.py           งานหนึ่งไฟล์: ชิ้นส่วน กลุ่มวัสดุ+ความหนา การตรวจสอบ
      layout.py            วางชิ้นในไฟล์ DXF / แบ่งแผ่นเหล็ก
      dxf_export.py        เขียน DXF (ezdxf)
      xlsx_export.py       เขียน Excel (openpyxl)
      sw_convert.py        .sldasm -> STEP ผ่าน SolidWorks COM (ยังไม่ได้ทดสอบ)
    web/                   index.html, style.css, app.js (ไม่ต้อง build)
  tests/                   pytest: ชิ้นงานสังเคราะห์ที่รู้คำตอบ + เทียบไฟล์ SolidWorks
```

API สำคัญ: `POST /api/upload`, `GET /api/jobs/{id}`, `PATCH /api/jobs/{id}/parts/{pid}` (`material_id`, `t_override`, `include`, `flip`), `PATCH /api/jobs/{id}/settings`, `GET /api/jobs/{id}/export/{dxf/<กลุ่ม>/<แผ่น>|xlsx|all}`, `GET/PUT /api/profiles`

## เวอร์ชันตัวอย่างออนไลน์ (GitHub Pages)

GitHub Pages เปิดได้แค่ไฟล์หน้าเว็บ รัน Python และ OpenCASCADE ที่ใช้คลี่แผ่นไม่ได้ หน้าเว็บบน Pages จึงเป็น **เวอร์ชันตัวอย่าง**
ที่แสดงผลจากงานตัวอย่าง `DemoCabinet` (ตู้เหล็กสังเคราะห์ 8 แบบ 27 ชิ้น) ซึ่งคำนวณด้วยโปรแกรมจริงไว้ล่วงหน้า
กดดูใบสั่งตัด แบบคลี่ วัดระยะ และดาวน์โหลด DXF/Excel ของงานตัวอย่างได้ แต่ส่งไฟล์ของตัวเองเข้าไปคลี่ไม่ได้

ใช้งานจริงกับไฟล์ของคุณ: ดาวน์โหลดโปรเจกต์นี้ (Code → Download ZIP) แตกไฟล์ แล้วดับเบิลคลิก `start.bat` (ต้องมี Python 3.10+)

สร้างไฟล์ตัวอย่างใหม่หลังแก้โค้ด: `python tools/build_demo.py` (เขียนลงโฟลเดอร์ `docs/` ที่ Pages ใช้)

## ใช้งานออนไลน์ได้จริง (deploy ขึ้นคลาวด์)

GitHub Pages รันโปรแกรมคลี่แผ่นไม่ได้ ถ้าอยากให้คนอื่นอัปโหลดไฟล์ผ่านลิงก์ได้เลย ต้องรันโปรแกรมเป็น container บนคลาวด์ โปรเจกต์นี้เตรียมไว้แล้ว (`Dockerfile`)
และทุกครั้งที่ push จะมี GitHub Action สร้าง container แล้วลองอัปโหลดงานตัวอย่างจริงเพื่อตรวจว่าใช้งานได้

เมื่อรันบนคลาวด์ (`SHEETFLAT_CLOUD=1`) โปรแกรมจะ ปิดการเปิดไฟล์ด้วยพาธ ลบไฟล์ที่อัปโหลดทันทีหลังอ่านเสร็จ งานหมดอายุใน 2 ชั่วโมง และจำกัดไฟล์ไม่เกิน 100 MB
ข้อควรรู้: ไฟล์ลูกค้าจะถูกส่งขึ้นเซิร์ฟเวอร์ภายนอก, ตารางค่ายืดที่แก้บนเว็บใช้ร่วมกันทุกคนและหายเมื่อ container รีสตาร์ต (แก้ค่าเริ่มต้นถาวรที่ `sheetflat/core/profiles.py`)

| ที่ไหน | ค่าใช้จ่าย | วิธี |
|---|---|---|
| **Render** (ง่ายสุด) | ฟรี (หลับเมื่อไม่มีคนใช้ 15 นาที เปิดครั้งแรกรอ ~1 นาที, RAM 512 MB) | กด https://render.com/deploy?repo=https://github.com/woraphontrangpanich-jpg/LHPsolidwork แล้วล็อกอินด้วย GitHub ระบบอ่าน `render.yaml` เอง |
| **Cloudflare Containers** | ต้องมี Workers Paid $5/เดือน (มีโควตา CPU/RAM รวมให้) | สร้าง API token ใน Cloudflare ใส่ repo secrets `CLOUDFLARE_API_TOKEN` และ `CLOUDFLARE_ACCOUNT_ID` แล้วรัน Action “Deploy to Cloudflare Containers” (ไฟล์ตั้งค่าใน `cloudflare/`) |
| **Google Cloud Run** | มีโควตาฟรีรายเดือน ต้องผูกบัตร | `gcloud run deploy sheetflat --source . --memory 1Gi --max-instances 1` |

โปรแกรมเก็บงานไว้ในหน่วยความจำ จึงต้องตั้งให้รันแค่ 1 instance
