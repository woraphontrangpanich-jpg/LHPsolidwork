SheetFlat
ทดลองใช้งาน ดาวน์โหลดโปรแกรม
เวอร์ชันตัวอย่างออนไลน์ แสดงผลจากงานตัวอย่างที่คำนวณไว้แล้ว การคลี่ไฟล์ของคุณเองต้องดาวน์โหลดโปรแกรมไปรันในเครื่อง วิธีติดตั้งในเครื่อง

คลี่แบบ 3D เป็นแผ่นเรียบ แยกไฟล์ตัดตามความหนาเหล็ก

อัปโหลด Assembly ของลูกค้า โปรแกรมหาความหนาของทุกชิ้น หักค่ายืดตรงรอยพับ แล้วรวมชิ้นที่หนาเท่ากันไว้ใน DXF ไฟล์เดียว พร้อมใบสรุป Excel

ดาวน์โหลดไฟล์ STEP ตัวอย่าง

  1. เลือกเหล็กของงานนี้

    ชิ้นที่ใช้เหล็กต่างชนิด แก้รายชิ้นได้หลังคำนวณเสร็จ

  2. โหมดค่ายืด

  3. วางไฟล์ Assembly

    ลากไฟล์ .step มาวาง หรือกดเพื่อเลือก

    .step และ .stp ใช้ได้ทันที · .sldasm ใช้ได้เฉพาะเครื่องที่ติดตั้ง SolidWorks · ไฟล์งานที่บันทึกไว้ (.sheetflat) วางที่นี่ได้เหมือนกัน

    หรือเปิดไฟล์ในเครื่องนี้ด้วยพาธ

ดาวน์โหลด SheetFlat ไปใช้ในเครื่อง

เวอร์ชันในเครื่องคลี่ไฟล์ STEP ของคุณได้จริง ใช้ได้ทุกฟังก์ชัน และไฟล์งานของลูกค้าไม่ถูกส่งขึ้นอินเทอร์เน็ต

ดาวน์โหลด SheetFlat (ZIP)

SheetFlat-windows.zip · Windows 10 / 11 (64-bit) · ประมาณ 180 MB · มีทุกอย่างในไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม

  1. แตกไฟล์ ZIP

    คลิกขวาที่ไฟล์ที่ดาวน์โหลดมา เลือก Extract All… (แตกไฟล์ทั้งหมด) แล้วเลือกที่เก็บ เช่น D:\ จะได้โฟลเดอร์ชื่อ SheetFlat

  2. ดับเบิลคลิก SheetFlat.cmd

    ครั้งแรก Windows จะถามว่าจะเปิดไฟล์จากอินเทอร์เน็ตไหม ให้กด Run (เรียกใช้) ถ้าขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC” ให้กด More info แล้วกด Run anyway หน้าจอนี้ขึ้นกับโปรแกรมที่ยังไม่มีใบรับรองผู้พัฒนา

  3. เริ่มใช้งาน

    เบราว์เซอร์จะเปิดหน้า SheetFlat ให้เองภายในไม่กี่วินาที ห้ามปิดหน้าต่างสีดำระหว่างใช้งาน อยากได้ไอคอนบนหน้าจอ ให้คลิกขวาที่ SheetFlat.cmd แล้วเลือก Send to → Desktop

ปลอดภัยอย่างไร: ไฟล์ ZIP สร้างโดย GitHub Actions จากโค้ดใน repo นี้ ทุกเวอร์ชันล็อกไว้ไม่เปลี่ยนภายหลัง ไม่มีสคริปต์ดาวน์โหลดโค้ดมารันเพิ่ม และโปรแกรมทำงานในเครื่องเท่านั้น ไม่ส่งไฟล์งานขึ้นอินเทอร์เน็ต

ตรวจไฟล์ (SHA-256):
เปิด PowerShell แล้วพิมพ์ Get-FileHash SheetFlat-windows.zip ค่าที่ได้ต้องตรงกัน
