เปิดโปรแกรมครั้งแรก ตั้งรหัส 2 แบบก่อนเริ่มใช้งาน

หน้าเข้าใช้งานจะมีช่องใส่รหัสช่องเดียว พนักงานจึงไม่รู้ว่ามีรหัส 2 แบบ อยากให้พนักงานติดตั้งโดยใช้รหัสเดียวกับเครื่องนี้ ให้ไปที่เมนู ⋯ → สร้างตัวติดตั้งสำหรับพนักงาน

คลี่แบบ 3D เป็นแผ่นเรียบ แยกไฟล์ตัดตามความหนาเหล็ก

อัปโหลด Assembly ของลูกค้า โปรแกรมหาความหนาของทุกชิ้น หักค่ายืดตรงรอยพับ แล้วรวมชิ้นที่หนาเท่ากันไว้ใน DXF ไฟล์เดียว พร้อมใบสรุป Excel

ดาวน์โหลดไฟล์ STEP ตัวอย่าง

  1. เลือกเหล็กของงานนี้

    ชิ้นที่ใช้เหล็กต่างชนิด แก้รายชิ้นได้หลังคำนวณเสร็จ

  2. โหมดค่ายืด

  3. วางไฟล์ Assembly

    ลากไฟล์ .step มาวาง หรือกดเพื่อเลือก

    .step และ .stp ใช้ได้ทันที · .dxf (แบบคลี่ที่มีอยู่แล้ว) เปิดได้ โดยทุกเส้นขอบปิดเป็น 1 ชิ้น · .sldasm ใช้ได้เฉพาะเครื่องที่ติดตั้ง SolidWorks · ไฟล์งานที่บันทึกไว้ (.sheetflat) วางที่นี่ได้เหมือนกัน

    หรือเปิดไฟล์ในเครื่องนี้ด้วยพาธ

ดาวน์โหลด SheetFlat ไปใช้ในเครื่อง

เวอร์ชันในเครื่องคลี่ไฟล์ STEP ของคุณได้จริง ใช้ได้ทุกฟังก์ชัน และไฟล์งานของลูกค้าไม่ถูกส่งขึ้นอินเทอร์เน็ต

ดาวน์โหลด SheetFlat

SheetFlat-Setup.exe · Windows 10 / 11 (64-bit) · ประมาณ 110 MB · มี Python และทุกอย่างที่โปรแกรมต้องใช้ในไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม

  1. ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา

    ถ้าขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC” ให้กด More info แล้วกด Run anyway หน้าจอนี้ขึ้นกับโปรแกรมที่ยังไม่มีใบรับรองผู้พัฒนา

  2. กดถัดไปจนเสร็จ

    ใช้เวลาไม่ถึงนาที ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่ต้องต่ออินเทอร์เน็ต

  3. เปิดจากไอคอน SheetFlat

    ไอคอนอยู่บนหน้าจอและในเมนู Start โปรแกรมเปิดในหน้าต่างของตัวเอง ปิดหน้าต่างเมื่อเลิกใช้งาน

ตั้งรหัสให้ไฟล์ติดตั้ง ก่อนส่งต่อให้พนักงาน

ใส่รหัสลงในไฟล์ Setup ที่ดาวน์โหลดมาได้เลย ไม่ต้องติดตั้งก่อน ทุกเครื่องที่ติดตั้งจากไฟล์ที่ได้จะใช้รหัสชุดนี้ และเปิดมาเจอหน้าใส่รหัสทันที ไฟล์และรหัสไม่ถูกส่งขึ้นอินเทอร์เน็ต ทำในเบราว์เซอร์นี้ทั้งหมด

ได้ไฟล์ SheetFlat-Setup.exe ที่มีรหัสแล้ว ส่งไฟล์นี้ให้พนักงานติดตั้งได้เลย

ปลอดภัยอย่างไร: ไฟล์ติดตั้งสร้างโดย GitHub Actions จากโค้ดใน repo นี้ ทุกเวอร์ชันล็อกไว้ไม่เปลี่ยนภายหลัง ไม่มีสคริปต์ดาวน์โหลดโค้ดมารันเพิ่ม และโปรแกรมทำงานในเครื่องเท่านั้น ไม่ส่งไฟล์งานขึ้นอินเทอร์เน็ต

ตรวจไฟล์ (SHA-256):
เปิด PowerShell แล้วพิมพ์ Get-FileHash SheetFlat-Setup.exe ค่าที่ได้ต้องตรงกัน

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดไฟล์ติดตั้งใหม่แล้วติดตั้งทับได้เลย ตารางค่ายืดและราคาที่ตั้งไว้ไม่หาย

ไม่อยากติดตั้ง: ดาวน์โหลดแบบ ZIP แตกไฟล์ แล้วดับเบิลคลิก SheetFlat.cmd
